- Exports: `ChangesStore`, `ScopedDiff`, `ChangesSnapshot`, `ChangesClient`, `WATCH_RETRY_MS = 2000`.
- `ScopedDiff = {diff: CheckoutDiff, scope: DiffScope, baseRef: string|null, commitSha: string|null, key: string}` — key = `` `${scope}:${baseRef}:${commitSha}:${cwd}:${chatId}:${watchSum}` `` (watchSum = resolved working-tree `checksum`).

- Wire: constructor subscribes `client.watch(methods.WATCH_CHECKOUT_DIFFS, {}, {onItem, onEnd})`. `onItem`: array frame replaces `working` wholesale; single frame goes through `upsertDiffFrame`; generation bump resets everything. `onEnd`: `error = "Diff stream interrupted — retrying"` (clean end) or `"Diff watch unavailable: ${error.message}"`; content stays; `#scheduleRetry()` re-subscribes after flat 2000 ms.

Failures land in `scopedError` (separate from the watch banner).
- `resubscribe()` (session swap): cancels retry + watch, clears state, re-subscribes. `dispose()` cancels everything.
