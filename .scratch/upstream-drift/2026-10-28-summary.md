# Zeron vs Roboco: the short version (2026-10-28)

**What was checked:** every Zeron change since we stopped merging (576 commits, up to v0.2.127), all of Zeron's open and closed pull requests, and a side-by-side feature comparison of both desktop apps and of Zeron's iPhone app vs our Android app.

**Bottom line:**
- About 85% of Zeron's changes are already in Roboco, or deliberately left out (cloud, iOS, macOS).
- What's left: **about 25 real bugs**, **about 15 features worth taking**, **about 15 Android gaps**, and **a handful of CI fixes**.
- The numbers in brackets (A12, B, C…) point to the full report (`2026-10-28.md`) if you want the details.

---

## 1. Bugs we have today (fix these first)

**Crashes and security**
- A deeply nested Markdown message can crash the app, on desktop and Android. (A36)
- Markdown renders wrong while an agent is streaming: lists, links, checkboxes. (A36b)
- The files editor can crash after a file changes on disk. (A5)
- Any program on your PC can control the Roboco engine, because there's no secret token. (A40)
- The desktop opens any sign-in link an engine sends, including from a paired engine. (A9)

**Windows**
- Windows 10: the window's minimize, maximize and close buttons are blank. (A3)
- No notification banners, only the sound. (A4)
- File paths in replies (`C:\…`) aren't clickable. (A11, A39)
- Codex "Run" titles show `powershell.exe -Command …` instead of the command. (A12)
- Terminals can open in `C:\Windows` for some folders. (A8)
- Model picker shortcuts use the Windows key instead of Ctrl. (A28)
- New project doesn't recognise `c:\users\…` (lower-case drive letter). (A33)

**Agents and orchestration**
- Codex chats fail any Roboco tool call that takes over 60 seconds (e.g. `wait_for_turn`). (A2)
- `create_chat` can pick Claude even when it isn't signed in, so the new chat fails. (A30)
- `wait_for_turn` reports an interrupted chat as "completed". (A31)
- Zeron's "make every agent sturdier" update is only partly in Roboco (14 pieces missing). (A37) Examples:
  - OpenCode chats stuck on "Working" for up to 30 minutes after a crash;
  - Stop doesn't stop OpenCode subagents;
  - Claude hangs if it crashes after the first turn.
- Claude agents inherit Claude Code session settings when Roboco is started from one. (A26)
- Pi chats have no slash-command menu. (A43)

**Sidebar and chat**
- The "+" new-chat button never shows on git projects. (A1)
- A chat you leave quickly shows "Failed" while it's actually running. (A6)
- A forked chat's subagent chips spin forever. (A7)
- Images Codex generates show on Android but not on desktop. (A18)
- The raw `[Message from Roboco chat …]` text shows in the queue (desktop) and in every bubble (Android). (A15)
- Forking a chat on another fleet engine gives no feedback and blocks other forks. (A46)

## 2. Zeron features we don't have (worth taking)

- **Nicer agent messages:**
  - "Message from ✳ Chat" above the bubble instead of inside it;
  - Markdown inside message bubbles;
  - outgoing messages shown as one line ("Message to X"). (B, #1052, #1067, #1068)
- **Agents keep running when you quit the app** (the engine runs as its own background process). (A41)
- **Claude subagents stream live**, and a typed `/skill` gets its own tab. (B)
- **Agents can show images in chat**, and you can close a question without answering. (B)
- **First-run setup** (welcome → look → agents → first project), on desktop and Android. (A27)
- **Settings:** a Worktrees page, searching Settings, and a switch to turn native subagents off. (B)
- **Polish:**
  - smooth mouse-wheel scrolling;
  - tooltips on icon buttons;
  - "● 3 running" subagent pill in the sidebar;
  - session hover card;
  - transcript rail. (B)
- **Bigger:**
  - terminal overhaul (faster typing, better TUI support);
  - workspace search in Ctrl+K;
  - in-app browser on Windows;
  - Linux browser upgrade. (B)
- **Terminal programs report their status** (idle/working/blocked) to the sidebar. (B, #966)

## 3. Android (to match the iPhone app)

- Messages from other chats show raw routing text; need the "Message from" caption. (C)
- **You can't fix a signed-out agent from your phone.** When a chat fails because, say, Claude's login on your PC expired, the error card's **Log in** button only opens a screen saying "sign in from Roboco on your PC". On the iPhone, Log in (or **Add account** in Settings → Accounts) starts the sign-in on the PC and opens the sign-in page on the phone; you log in there and the PC's agent is signed in. The engine already supports it. Codex/ChatGPT also need A42. (C, N3)
- No **Delete session**. The core already supports it; it only needs the button. (C)
- One-row bottom bar, tabbed model picker, and showing the default model name instead of "Claude Code". (C, I2)
- A phone in landscape switches to the tablet layout. (I1)
- Switching agents mid-chat is invisible in the transcript. (N1)
- Providers: turn agents on or off per computer. (N2)
- Drag sessions between sections; first-run setup; small toast polish. (C)

## 4. CI

- Windows tests never run on pushes to `main`, only on PRs. (D)
- Two Windows checks exist in the repo but aren't wired into CI. (D)
- Every PR saves its own build cache, which wastes cache space. (D)
- GitHub Actions aren't pinned to exact versions, and the release workflow holds the Android signing keys. (D)
- The Android build probably compiles the core twice. (A47)
- *(A separate CI-speed study is running; results go to `.scratch/ci-speed/`.)*
