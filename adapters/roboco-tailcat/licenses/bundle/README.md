# Tailcat adapter redistribution licenses

This directory contains the original Kratos distribution's license and patent-notice files for the Go modules compiled into the statically linked `roboco-tailcat` adapter, plus the Go standard library/runtime license. Source versions are recorded in `DEPENDENCIES.txt`.

Originally generated for the equivalent managed adapter on linux/amd64, linux/arm64, darwin/amd64, darwin/arm64, windows/amd64, windows/arm64 with go1.27.1. The dependency closure is pinned in the checked-in `go.mod`/`go.sum`; license bytes come from verified Go module-cache directories, not repository URLs.
